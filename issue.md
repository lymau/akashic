# Issue: Multi-topic Docusaurus site (separate docs per topic + topic hub homepage)

## Goal

Turn the freshly installed Docusaurus site into a personal learning journal with **three separate topic sections**, each with its own sidebar and URL, plus a **homepage that shows one card per topic**.

| Topic       | URL prefix     | Folder         | Sidebar file                | Sidebar id           |
| ----------- | -------------- | -------------- | --------------------------- | -------------------- |
| Japanese    | `/japanese`    | `japanese/`    | `sidebars-japanese.js`      | `japaneseSidebar`    |
| Programming | `/programming` | `programming/` | `sidebars-programming.js`   | `programmingSidebar` |
| Marketing   | `/marketing`   | `marketing/`   | `sidebars-marketing.js`     | `marketingSidebar`   |

The blog stays as one shared blog at `/blog`, using tags to separate topics.

## Rules (read first)

- Work only inside the Docusaurus project root (the folder that contains `docusaurus.config.js`, or `docusaurus.config.ts` if the project uses TypeScript).
- Do **not** install or upgrade any packages.
- Do **not** change `url`, `baseUrl`, `organizationName`, or `projectName` in the config. Deployment is handled separately.
- Do the tasks in the order written. Run the check at the end of each task.
- Use `Link` from `@docusaurus/Link` with the `to` prop for internal links in React code. Never use `<a href="/...">` for internal links, because it breaks when the site is hosted under a sub-path on GitHub Pages.
- If the project uses TypeScript (`.ts` config files), keep the same content but use `export default` instead of `module.exports`.

## Task 4: Build the topic hub homepage

### 4a. Replace `src/pages/index.js` completely

```jsx
import React from 'react';
import Layout from '@theme/Layout';
import Link from '@docusaurus/Link';
import Heading from '@theme/Heading';
import styles from './index.module.css';

const topics = [
  {
    icon: '🗾',
    title: '日本語 Japanese',
    desc: 'Grammar, vocabulary, and my study log.',
    link: '/japanese/intro',
  },
  {
    icon: '💻',
    title: 'Programming',
    desc: 'Things I built and learned.',
    link: '/programming/intro',
  },
  {
    icon: '📈',
    title: 'Marketing',
    desc: 'Notes, frameworks, and case studies.',
    link: '/marketing/intro',
  },
];

export default function Home() {
  return (
    <Layout
      title="Learning Journal"
      description="My notes on Japanese, programming, and marketing">
      <header className={styles.hero}>
        <div className="container">
          <Heading as="h1" className={styles.heroTitle}>
            My Learning Journal
          </Heading>
          <p className={styles.heroSubtitle}>
            Everything I learn, written down. Pick a topic to start.
          </p>
        </div>
      </header>
      <main className="container margin-vert--xl">
        <div className="row">
          {topics.map((topic) => (
            <div className="col col--4 margin-bottom--lg" key={topic.title}>
              <Link className={styles.card} to={topic.link}>
                <div className={styles.cardIcon}>{topic.icon}</div>
                <Heading as="h2">{topic.title}</Heading>
                <p>{topic.desc}</p>
              </Link>
            </div>
          ))}
        </div>
      </main>
    </Layout>
  );
}
```

## Troubleshooting

| Error message or symptom                                  | Likely cause and fix                                                                                   |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `Broken link on source page path = /...` pointing to `/docs/intro` | A footer or navbar link still points to `/docs/...`. Fix it as in Task 3c and 3d.             |
| `Sidebar ... not found` or navbar item missing            | `sidebarId` in the navbar does not match the key in the sidebar file. Compare the spelling exactly.    |
| Plugin id error                                           | Two plugins share the same `id`. Each must be unique: `japanese`, `programming`, `marketing`.          |
| Empty sidebar                                             | The folder has no `.md` files, or `path` in the plugin does not match the folder name.                 |
| Card link gives 404                                       | The target `intro.md` is missing `id: intro`, or the folder name does not match `routeBasePath`.       |
| Cannot resolve `@theme/Heading`                           | Older Docusaurus. Use plain `h1` / `h2` tags as noted in Task 4a.                                      |
